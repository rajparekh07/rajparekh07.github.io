# Raj Parekh — portfolio

Minimal, responsive portfolio and résumé site for Raj Parekh.

## Structure

- `index.html` — semantic site content and metadata
- `styles.css` — responsive visual system
- `favicon.svg` — compact RP site mark
- `og-image.png` — social sharing preview
- `robots.txt` and `sitemap.xml` — crawler discovery and indexing signals
- `site.webmanifest` — install and application metadata

The site has no runtime dependencies and is deployed directly with GitHub Pages.
